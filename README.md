
# Minha Primeira Página HTML

Este é meu primeiro projeto desenvolvido durante meus estudos de Análise e Desenvolvimento de Sistemas (ADS).

## Sobre o projeto

Criei uma página HTML para apresentar o Conecta Fácil, uma proposta de inclusão digital para idosos.

## Tecnologias utilizadas

- HTML5
- Visual Studio Code
- Git e GitHub

## O que aprendi

- Criar a estrutura básica de uma página HTML.
- Utilizar títulos, parágrafos e listas.
- Organizar arquivos no VS Code.
- Registrar alterações com Git.
- Publicar um repositório no GitHub.

## Próximos passos

Continuar meus estudos de HTML, CSS e JavaScript para desenvolver novas funcionalidades do Conecta Fácil.
